# weavec0 test ladder manifest
#
# Each non-blank, non-comment line lists one test case.
# Two flavours:
#
#   pass <name> <expected_exit_code>
#     - compiles test/<name>.wir, asserts the generated .ll matches
#       test/<name>.expected.ll, then runs the executable and checks its
#       exit code.
#
#   fail <name> <expected_diagnostic_substring>
#     - compiles test/<name>.wir, expects weavec0 to exit non-zero, no .ll
#       produced, and stderr to contain the given substring.
#
# The expected_diagnostic_substring may contain spaces. Quote with care.
# Numeric prefixes are conventional: 01-49 = original ladder, 50-59 = parse
# / compile-fail cases, 60+ = later additions slotted into theme gaps.
#
# Adding a test: it must exercise behavior the parser/emitter already admits.
# Do not extend the language to make a test pass. See README "Test Ladder".
